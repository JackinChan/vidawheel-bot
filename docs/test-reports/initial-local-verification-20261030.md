## 环境与范围

Python 3.12、PostgreSQL 17 Docker 容器、MCP SDK 1.30.0、飞书 SDK 1.7.5。数据库与 MCP 分别为本项目独立容器，MCP 仅映射回环地址。使用合成应用、员工、事件和临时生成凭据，无真实飞书调用或消息发送。

## 已验证

`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1` 下执行 `tests/test_integration.py`，4 项测试通过，实际连接 PostgreSQL：

- 同一 bot/event_id 重复投递不新增任务；不允许的群、缺少机器人提及被忽略。
- app_id 不匹配被拒绝；不同 bot 授权范围看不到任务。
- 并发领取只有一位成功；过期重新领取产生不同令牌，旧工作者无法提交。
- 不同员工不能提交他人任务；释放后可重新领取，重试次数累计。

通过官方 MCP 客户端对 Docker 服务的 `/mcp` 发起真实 HTTP 调用，验证匿名 401、认证后的初始化、6 项工具发现、任务列表、领取、上下文、续租和结果提交。未绕过 MCP 直接调用业务函数代替 HTTP 验收。

首次 HTTP 检查受到本机 localhost 代理影响返回 502；验收脚本明确直连 127.0.0.1 且不继承代理配置后通过。此处理仅用于本地验收客户端。
